# Sim(3) pipeline 与核心参数

## 任务边界

给定带外点对应集合 `C={(x_i,y_i)}`，求 `y_i≈sRx_i+t`。尺度是全局统一的正数；各节点的 `s_i` 是为了识别可靠对应关系而估计的局部证据，不是最终的非刚性尺度场。该实现不是非刚性配准，也不自动完成无对应点点云匹配。

主要实现：`turboreg/src/scale_turboreg.cpp`；公开接口：`turboreg/include/turboreg/sim3.hpp`；RANSAC：`turboreg/src/sim3.cpp`。

## 逐步流程

1. **输入与预算。** 检查形状、点数、有限值、设备和浮点类型。取前 `max_points` 条，转 float32。CPU / CUDA 都构造全点对距离 `d^x_ij, d^y_ij`，没有自动归一化坐标。
2. **局部尺度。** 在源和目标分别找 KNN，明确排除自身索引，取邻居索引并集。对同一对应边计算 `s_ij=d^y_ij/d^x_ij`；两侧距离都必须大于 `min_pair_distance`，比值落在 `(scale_min,scale_max)`。默认在 log 域按 `log_scale_bin_width` 分桶，选最高票桶，桶内 log 均值取指数得到 `s_i`。票数相同选最小桶编号；无合法投票时回到 `s_i=1`，这是局部尺度缺少证据时的默认值，不是求解成功。
3. **三尺度一致性（TSC）。** 对每条潜在边检查：

   `max(log s_i, log s_j, log s_ij) - min(log s_i, log s_j, log s_ij) < epsilon_scale`。

   “三尺度”是**两个节点尺度 + 一条边尺度**，不是三条边，也不是最终的三个全局尺度。还需尺度范围合法、源距离非零、`d^x_ij+d^y_ij > nms_radius`。这里 `nms_radius` 实际是排除过近点对的距离和阈值，不是通常意义上的关键点 NMS。
4. **二阶支持。** 得到对称二值邻接矩阵 `A`。边评分 `S=(A@A)⊙A`，即合法边的公共邻居数量。关闭二阶评分时 `S=A`。
5. **TurboClique 假设生成。** 在上三角选择评分为正的前 `num_pivots` 条枢轴边 `(i,j)`；从公共邻居中选最多两个第三点 `k>j`，按三边评分之和排序。只保留实际存在的三点团；候选数至多 `2*num_pivots`。这是受限候选搜索，不是枚举所有最大团。
6. **退化剔除 + Umeyama。** 源、目标三角形都要求 `||e01×e02|| > 1e-4 * max_edge²`；即排除重复点或近共线的最小集。对剩余三点团批量求 SVD，反射修正使 `det(R)=+1`，从协方差和源方差估计 `s`，再求 `t=μ_y-sRμ_x`。求解器不把尺度硬截断到 `[0.1,10]`。
7. **验证。** 每个假设将源点变换到目标坐标；以目标单位残差 `r_i=||sRx_i+t-y_i||` 评分。`IN` 为内点数；`MAE` 为 `Σmax(1-r_i/τ,0)`；`MSE` 为 `Σmax(1-r_i/τ,0)²`，两者都不是无截断的平均误差。每批最多验证 128 个假设以约束显存。
8. **重建图与精修。** 最优模型的内点数至少 10 时，可在内点子集重算前述流程，最多 `graph_iterations` 轮。最后回到最初预算内的全部对应点，用 `w_i=1/(1+(r_i/τ)²)` 做内点加权 Umeyama，最多 `refinement_iterations` 轮，内点掩码稳定则停止。
9. **输出。** 返回 `[sR,t;0,1]`、尺度、全部输入点的内点掩码、输入数、求解使用数和内点数。至少三条一致对应仅表明有候选模型，无法替代 GT 指标或下游质量门限。输入错误、图中没有可用候选等情况明确失败。

## 核心参数

以下是当前 `Sim3Options` 的起始默认值，尚不是经验证集选择的最优参数。

| 参数 | 默认 | 含义与调参重点 |
|---|---:|---|
| `epsilon_scale` | 0.1 | TSC 的 log 尺度跨度阈值；约允许三个尺度最大/最小比小于 `exp(0.1)≈1.105`。优先扫 0.05/0.1/0.15/0.2 |
| `k_neighbors` | 20 | 每侧 KNN 数，并集至多 2K；扫 10/20/40/80，影响局部投票可靠性 |
| `log_scale_bin_width` | 0.1 | log 直方图桶宽；与 TSC 阈值独立。扫 0.05/0.1/0.2 |
| `inlier_threshold` | 0.1 | 目标坐标系的残差阈值，同时影响评分、筛内点、精修；米制室内起点为 10 cm |
| `num_pivots` | 2000 | 候选枢轴边预算；最多 4000 个三点团；扫 500/1000/2000/4000 |
| `max_points` | 7000 | 对应点预算；扫 1000/2500/5000/7000，主要影响图耗时与内存 |
| `nms_radius` | 0.15 | 排除 `d_src+d_dst≤radius` 的近距离边；源和目标都受影响，改变数据尺度/单位后需重新核验 |
| `graph_iterations` | 2 | 以当前内点重建图的最大轮数；扫 1/2/3 |
| `refinement_iterations` | 20 | 加权 Umeyama 上限；0 关闭，用于精修消融 |
| `scale_min`, `scale_max` | 0.1, 10 | 局部投票、节点和边的尺度先验范围，开区间；必须覆盖目标 `s=dst/src`。不是最终求解硬约束 |
| `min_pair_distance` | 0.001 | 局部尺度投票时排除过短基线，源/目标都要通过；依坐标单位设定 |
| `local_scale_mode` | hist | `hist` / `union_median` / `median`，用于局部尺度估计消融 |
| `metric` | IN | `IN` / `MAE` / `MSE`，含义见步骤 7 |
| `use_tsc` | true | false 时取消尺度一致性及范围门控，保留非零距离和近边排除 |
| `use_second_order` | true | false 使用一阶二值边评分 |
| `reject_degenerate` | true | false 关闭三角形面积过滤；仅作消融 |

`median` 模式用两侧独立 KNN 距离中位数的比值；它与同一邻居边的比值中位数不同，更易受采样密度差异影响。`union_median` 才是并集对应边尺度的中位数。

不要仅因为绝对尺度大就自动放宽 `epsilon_scale`：它限制的是局部估计之间的相对分歧，应该由噪声、外点和邻域质量决定。测试集尺度范围是实验协议的一部分，不能逐对用 GT 调整参数。

## 兼容接口中的旧参数

- `ScaleTurboRegGPU` / `run_reg` 保留；新接口采用具名 `Sim3Options`。
- 旧 Python `graph_k` 一直被忽略；旧 C++ / Python `trim_ratio` 不参与现行局部尺度估计。新接口不暴露这两个无效参数。
- 旧 `local_scale_diff` 实际控制直方图桶宽，默认跟随 `epsilon_scale`；新接口用清楚的 `log_scale_bin_width`，默认 0.1。
- 旧 `use_distance_diff_consistency` 使用 `|d_src-d_dst|`，是刚性一致性对照；新 Sim(3) 接口不暴露它。

## 实现边界与复杂度

- 与清理前 GPU 主流程一致，现在 CPU 也用稠密全点对图。旧 CPU 的 KNN 稀疏图路径已删除，因此旧 CPU 实验结果需要重跑。
- 距离/邻接矩阵空间复杂度 `O(N²)`；稠密二阶矩阵乘法算术复杂度 `O(N³)`，候选验证 `O(KN)`。7000 对应点时一个 float32 方阵约 196 MB，多个并存，不能只按一个矩阵估算显存。
- 局部直方图在 C++ 主机代码中计算，CUDA 会有距离/邻居数据回传；不能宣称整个流程无 CPU 同步。
- 同分候选的 `topk` 在不同设备上不保证同一顺序；统一数学流程不保证 CPU/GPU 逐位相同或相同耗时。
- `NoGradGuard` 下运行，是离散稳健求解器，不提供可微反向传播。
- 不承诺低于某一内点率一定成功；重复结构可能产生大规模错误一致集，需用失败案例和内点率分桶实验检验。
